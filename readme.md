# Credentials

Certificates and credentials of Adam Ross DeStafeno (Ryuukae), shown as a gallery with links to
view, download and verify each one.

Live site: https://pages.ryuukae.io/credentials/

## Development

```bash
npm install
npm run dev
npm run build
```

## Structure

- `index.html`: page markup.
- `src/styles/`: color palette, base, font and keyframe styles.
- `src/scripts/canvas/`: animated network background and header.
- `src/scripts/main.js`: entry point.
